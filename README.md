# 🎬 TMDB Proxy Server

A lightweight Node.js + Express backend server that securely proxies requests to the TMDB API.

This server was built to bypass regional blocking (especially common in India, e.g., Jio networks) and ensure that the [🚀Netflix-GPT App](https://gpt-netflex.netlify.app/) can fetch movie/TV data without interruptions.

## 🌍 Live Server

Deployed on **Render**:  
🔗 [https://tmdb-proxy-server-w1ng.onrender.com](https://tmdb-proxy-server-w1ng.onrender.com)

Example endpoint:

```bash
https://tmdb-proxy-server-w1ng.onrender.com/upcoming

```

## 💻 Tech Stack

- Node.js + Express – Server framework
- TMDB API – Movie & TV data source
- Render – Hosting and deployment
